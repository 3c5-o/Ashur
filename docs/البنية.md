# بنية آشور

## الأجزاء الرئيسية

- `apps/user-web`: واجهة المستخدم ونسخة الويب.
- `apps/admin-web`: واجهة الإدارة.
- `apps/site`: الموقع التعريفي وصفحة التحميل.
- `android/user`: غلاف أندرويد الهجين للمستخدم.
- `android/admin`: غلاف أندرويد الهجين للإدارة.
- `services/api`: بوابة آشور للخدمات والتخزين والإشعارات.
- `services/bot`: بوت إدارة قنوات التخزين.
- `supabase`: مخطط قاعدة البيانات.
- `infra`: ملفات النشر والبنية التحتية.

## قاعدة مهمة

تطبيقات المستخدم والإدارة لا تحتوي على توكن البوت، ولا رمز التجزئة، ولا مفتاح الخدمة السري. كل هذه القيم تبقى في الخادم فقط.
