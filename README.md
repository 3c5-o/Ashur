# آشور (Ashur) - المنصة الاجتماعية العربية الحديثة

منصة اجتماعية عربية شاملة للهاتف الذكي والويب، مبنية لتقديم تجربة تواصل متكاملة وسلسة تشمل المنشورات، الريلز، القصص، الرسائل الفورية، ولوحة إدارة متقدمة.

---

## المزايا الرئيسية

1. **الرئيسية والمنشورات**:
   - شريط قصص علوي يعمل على مدار ٢٤ ساعة.
   - تغذية منشورات تفاعلية تدعم الصور، الفيديوهات، النصوص، والإعجابات والتعليقات والمشاركات.

2. **الريلز (فيديو عمودي)**:
   - مشغّل ريلز بملء الشاشة مع التمرير السلس.
   - دعم التفاعل السريع والتعليقات والمشاركة.

3. **المحادثات والرسائل الفورية**:
   - محادثات فردية مباشرة وجماعية.
   - دعم الرسائل النصية، الصوتية، والمرفقات مع مؤشرات القراءة.

4. **البحث والاستكشاف**:
   - البحث في الحسابات، المنشورات، الهاشتاجات، والريلز.

5. **الملف الشخصي والخصوصية**:
   - إدارة الحسابات العامة والخاصة، طلبات المتابعة، وتخصيص المظهر (الوضع الداكن والفاتح).
   - التوثيق، الحظر، والمحفوظات.

6. **لوحة الإدارة المتكاملة**:
   - متاحة عبر مسار `/admin`.
   - إدارة المستخدمين، المحتوى، التعليقات، البلاغات، الدعم الفني، والتخزين.

---

## التشغيل والمسارات

- **تطبيق المستخدم الأساسي**: `/` أو `/app` أو `/apps/user-web/`
- **لوحة الإدارة**: `/admin` أو `/apps/admin-web/`
- **الموقع التعريفي**: `/site` أو `/apps/site/`
- **واجهة فحص الخادم**: `/health`
- **واجهات البرمجة الخلفية**: `/v1/...`
