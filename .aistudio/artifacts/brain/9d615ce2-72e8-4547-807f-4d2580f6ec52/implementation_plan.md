# خطة التحويل والتطوير الشامل لتطبيق آشور (Native APK System)

تحويل تطبيق آشور إلى نظام APK متكامل ذو طابع أصيل فائق السلاسة (Native-grade Mobile Experience) مستوحى من إنستغرام وثريدز، ومعالجة كافة المشاكل البصرية والوظيفية (تداخل شريط الحالة، اختفاء الصور الرمزية، تعليق الريلز، تداخل صورة الملف الشخصي، والمربعات غير المنسقة) لبناء تجربة تواصل اجتماعي عربية متكاملة.

---

### مراجعة المستخدم والقرارات الحاسمة

> [!IMPORTANT]
> تم تأكيد التفضيلات التالية بناءً على إجابات الأسئلة الاستيضاحية:
> 1. **النظام المعماري**: تجربة متكاملة بنظام APK وتصميم أصيل ومثالي (Native Mobile Look & Feel).
> 2. **الهوية البصرية**: نمط عصري أنيق مستوحى من إنستغرام وثريدز (Threads & Instagram) مع دعم الوضعين الفاتح والداكن ومراعاة كاملة للغة العربية والاتجاه من اليمين لليسار (RTL).
> 3. **الأولوية القصوى**: حل مشاكل عرض الصور الرمزية (Avatars)، مشغل الريلز والفيديو، حواف وشريط الحالة (Safe Insets)، وتخطيط البطاقات.

---

## 1. نظرة عامة والمفهوم الأساسي

* **الهدف الأساسي**: ترقية تطبيق آشور داخل حزمة الـ APK من مظهر صفحات الويب البسيطة إلى تطبيق هاتف عصري أصيل بالكامل، ذو استجابة لحظية، بدون نتوءات أو تداخلات مع نظام أندرويد.
* **الجمهور المستهدف**: المستخدمون العرب الباحثون عن منصة تواصل اجتماعي تجمع بين سرعة النشر، والقصص التفاعلية، والريلز، والرسائل الفورية، وحماية الخصوصية.
* **القيمة المضافة**: التخلص الجذري من العيوب البصرية (كالدوائر السوداء، وتداخل النصوص، ومربعات الاختيار البدائية) واستبدالها بعناصر تحكم وتصاميم أندرويد حديثة ومريحة للعين.

---

## 2. تجربة المستخدم والتصميم البصري (معالجة لقطات الشاشة الست)

بناءً على لقطات الشاشة الست التي أرفقها المستخدم، تم تحديد المشاكل ووضع الحلول المباشرة لها:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        معالجة مشاكل لقطات الشاشة                       │
├───────────────────────────────┬────────────────────────────────────────┤
│ المشكلة من لقطات الشاشة       │ الحل التصميمي المعتمد في الخطة         │
├───────────────────────────────┼────────────────────────────────────────┤
│ 1. تداخل شريط الحالة العلوي   │ تطبيق `env(safe-area-inset-top)` وضبط  │
│    مع عنوان "آشور"            │ شريط الأدوات العلوي بهوامش علوية كاملة │
├───────────────────────────────┼────────────────────────────────────────┤
│ 2. صور الحسابات تظهر كدوائر   │ معالجة بدائل الصور (Avatar Fallback)   │
│    سوداء صلبة في شاشة البحث   │ بألوان متدرجة أنيقة وحرف الاسم الأول    │
├───────────────────────────────┼────────────────────────────────────────┤
│ 3. تعليق شاشة الريلز في شاشة  │ إضافة معالجة ذكية لتشغيل الفيديو مع    │
│    سوداء ومؤشر تحميل لا ينتهي │ بوستر احتياطي (Poster Fallback) فوري   │
├───────────────────────────────┼────────────────────────────────────────┤
│ 4. شاشة الرسائل فارغة بدون    │ إضافة بطاقة "بدء محادثة جديدة" فورية   │
│    دعوة واضحة لبدء التفاعل    │ وتفعيل زر الإضافة المباشر              │
├───────────────────────────────┼────────────────────────────────────────┤
│ 5. صورة الملف الشخصي تتداخل   │ إعادة ترتيب رأس الملف الشخصي (Flex/Grid)│
│    فوق اسم المستخدم والنصوص   │ وفصل الصورة عن كتلة الاسم والنبذة       │
├───────────────────────────────┼────────────────────────────────────────┤
│ 6. مربعات الاختيار في         │ استبدال مربعات HTML بمفاتيح تبديل      │
│    الإعدادات بدائية كصفحة ويب │ أندرويد الحديثة (M3 Modern Switches)   │
└───────────────────────────────┴────────────────────────────────────────┘
```

### تفاصيل الواجهات الرئيسية:
1. **الرئيسية (Home Feed & Stories)**:
   * **شريط الحالة (Status Bar Insets)**: تباعد علوي نظيف لا يتداخل مع ساعة الهاتف أو نوتش الكاميرا.
   * **شريط القصص**: حلقة متدرجة أنيقة للأشخاص الذين لديهم قصص، مع بطاقة مميزة "قصتك" لإضافة قصة جديدة بتصميم متناسق.
   * **بطاقات المنشورات**: مظهر بطاقة ثريدز الحديثة؛ صورة كاملة مع زوايا مدورة ناعمة، شريط إجراءات تفاعلي (إعجاب بنبض أحمر، تعليق، مشاركة، حفظ)، وتنسيق واضح للنصوص والهاشتاغات.
2. **الاستكشاف والبحث (Search & Explore)**:
   * **شريط بحث عائم**: خلفية زجاجية ضبابية مع زر مسح سريع.
   * **تبويبات الأقسام**: أزرار كبسولية ناعمة (Pill Chips) تتماشى مع سمة التطبيق الفاتحة والداكنة.
   * **بطاقات الحسابات**: استبدال الدوائر السوداء بأفاتار جذاب يحمل أول حرف من اسم المستخدم مع تدرج لوني أو صورته المحملة، وزر "متابعة" بتصميم زر M3.
3. **مشغل الريلز السينمائي (Reels)**:
   * تحميل فيديو عمودي سريع التجاوب، مع عرض صورة الغلاف فورًا لمنع الشاشة السوداء.
   * عمود الإجراءات الجانبي الشفاف (إعجاب، تعليقات، مشاهدات، مشاركة) مع دوران أسطوانة الصوت.
4. **المحادثات والرسائل (Messages & Chat)**:
   * قائمة محادثات تفاعلية مع إمكانية بدء محادثة مباشرة مع أي حساب عبر ضغطة واحدة.
   * واجهة دردشة بنمط تليجرام/واتساب بفقاعات متدرجة للمرسل وظلية للمستلم، مع دعم التسجيل الصوتي وإرفاق الصور.
5. **الملف الشخصي (Profile)**:
   * غلاف علوي بانورامي، وأسفله صورة الحساب بموضع مدروس بدقة (لا يغطي الاسم أو اليوزر إطلاقاً).
   * إحصائيات المتابعين والمنشورات بخطوط عربية عصرية وواضحة، مع تبويبات سريعة للمنشورات والمحفوظات.
6. **شاشة الإعدادات العصرية (Settings)**:
   * استبدال كافة مربعات الاختيار بمفاتيح أندرويد التفاعلية (`Material Toggle Switches`).
   * تقسيم الإعدادات إلى مجموعات واضحة: المظهر، الحساب، الإشعارات، والدعم الفني.

## 3. القرارات التقنية والبدائل (Product Decisions & Trade-Offs)

* **القرار 1: حل مشكلة الأفاتار الأسود**:
  * *النهج المتبع*: توليد صور رمزية بديلة (Fallback SVG Avatars) مع تدرجات لونية جذابة وحرف الاسم العربي بخط نظيف عند غياب صورة الحساب، بدلاً من ترك وسم الصورة فارغاً أو داكناً.
  * *السبب*: القضاء التام على مظهر "الدوائر السوداء" التي ظهرت في لقطة شاشة البحث.
* **القرار 2: مشغل الريلز والمرونة الشبكية**:
  * *النهج المتبع*: فحص مسبق لملفات الفيديو، وتضمين آلية تشغيل متوافقة مع أندرويد WebView والأجهزة المختلفة مع عرض صورة المعاينة (Poster) حتى اكتمال التحميل.
  * *السبب*: منع شاشة التحميل السوداء الدائمة في شاشة الريلز.
* **القرار 3: مفاتيح تبديل الإعدادات (Native Switches)**:
  * *النهج المتبع*: استخدام كبسولات التبديل الحركية الحديثة (iOS / Android Material 3 Switches) مع دعم السحب واللمس.
  * *السبب*: نقل التطبيق من مظهر نموذج الويب القديم إلى مظهر تطبيقي احترافي.

### خطوات التنفيذ الميدانية:
1. **تحديث ملفات التنسيق والهندسة البصرية (`reference-ui-v5.css` و `style.css`)**:
   - تطبيق هوامش علوية دقيقة لجميع الصفحات والشاشات المنبثقة لمنع التداخل مع نوتش الشاشة.
   - إعادة بناء تخطيط رأس الملف الشخصي (Profile Header) لضمان نزول الاسم والبيانات أسفل صورة الحساب تماماً.
   - بناء مفاتيح أندرويد العصرية (CSS Material Switches) بدلاً من مربعات الـ Checkbox.
   - تلوين وتنسيق بطاقات الاستكشاف والتبويبات الكبسولية.
2. **تحديث كود الواجهة والتعامل مع الوسائط (`app.js` و `core.js`)**:
   - ترقية دالة `avatar()` لإنتاج أفاتار متدرج جذاب بحرف الاسم الأول بخلفية خضراء/زمردية أو زرقاء أنيقة.
   - تحسين منطق تشغيل الريلز (`loadReels`) بإضافة عرض الـ Poster والصوت وعلاج مشاكل انتظار التحميل.
   - تحسين عرض شاشة المحادثات لتوفير اقتراحات فورية لبدء المحادثات.
3. **تحديث وبناء حزمة الـ APK**:
   - تشغيل سكريبت بناء الـ APK ومزامنة كافة الأصول في المسار الأصلي.
   - توقيع الحزمة تلقائياً بمفاتيح أندرويد وتحديث `app/build/outputs/apk/debug/app-debug.apk`.
   - التحقق الكامل عبر أداة `compile_applet`.
