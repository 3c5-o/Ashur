# آشور

منصة اجتماعية عربية حديثة مستوحاة بصريًا من حضارة بلاد الرافدين.

هذا المستودع يجمع:
- تطبيق المستخدم الهجين.
- تطبيق الإدارة الهجين.
- بوابة الخادم.
- بوت إدارة التخزين وقنوات تيليجرام.
- خادم تيليجرام المحلي للملفات الكبيرة.
- الموقع التعريفي وصفحة التحميل.
- مخطط قاعدة البيانات وسياسات الحماية.

> الأسرار لا تُحفظ داخل المستودع. تُضاف لاحقًا كمتغيرات آمنة في بيئة التشغيل.
